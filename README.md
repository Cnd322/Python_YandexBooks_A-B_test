# Python_YandexBooks_A-B_test

 Исследовательский анализ сервиса ЯндексКниги
Цели и задачи проекта: 
* Необходимо проанализировать данные сервиса ЯндексКниги для регионов Москва и Санкт-Петербург. Получить и интерпретировать основные метрики прослушивания книг и провести A/B тестирование для гипотезы - пользователи из Санкт-Петербурга проводят в среднем больше времени за чтением и прослушиванием книг в приложении, чем пользователи из Москвы.

* Вторая часть проекта заключается в анализе проведенного A/B тестирования, корректного расчета метрик и расшифровки результатов после проведенного A/B теста.

 Структура проекта
Первая часть проекта:

* Загрузка и предобработка данных в тетрадке 
* Исследовательский анализ данных
* Статистический анализ гипотезы и выводы 

Вторая часть проекта:

* Загрузка данных и знакомство с ними 
* Корректность проведение теста и соответствие требованиям технического задания
* Анализ основных метрик теста между группами
* Расчет и анализ необходимой выборки для корректного теста
* Расчет основных статистик и проведение теста 
* Интерпретация результатов
